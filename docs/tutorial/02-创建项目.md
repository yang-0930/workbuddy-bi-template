# 创建项目：复制模板，开始动手

## 这一步要做什么

下载模板压缩包并解压，作为你的项目起点。

## 为什么做

模板已经把目录结构、开发规则、打包脚本都准备好了。你不用从零开始，复制一份往里填业务内容就行。

## 1. 下载并解压模板

先<a href="../downloads/template.zip" download>下载模板</a>，解压后把整个目录重命名成你的项目名，例如 `line-insight/`。

复制后你会得到这样的结构：

```
你的项目/
├── src/              # 看板页面放这里
├── dist/             # 打包后生成的离线文件在这里
├── .codebuddy/       # AI 工程配置（规则）
└── scripts/          # 打包脚本
```

## 2. 你的业务内容放哪

所有页面、图表、第三方库都放在 `src/` 目录下。AI 生成代码时也会自动往这里写。

::: tip 一句话
你负责把需求说清楚（下一章），AI 负责往 `src/` 里写代码，最后双击 `src/index.html` 就能看到结果。
:::

## 常见问题

- **Q：`.codebuddy` 目录能不能删？**
  A：可以删，但删掉后 AI 就不再自动遵守项目规则了。建议保留，不用管它。

## 成功标准

- [ ] 已下载解压模板，并重命名成自己的项目名
- [ ] 知道业务代码放在 `src/`，打包产物在 `dist/`
