# 教程图片目录

本目录存放教程中的所有图片（截图、示意图）。

## 目录约定

- 按章节分子目录，目录名对应 `docs/tutorial/` 下的章节：
  - `00-overview/` → 00-概述
  - `01-prepare/` → 01-准备
  - `02-project/` → 02-创建项目
  - `03-dashboard/` → 03-搭建面板
  - `04-deliver/` → 04-验证与交付
  - `05-faq/` → 05-常见问题
- 文件名用英文小写 + 短横线，描述图片内容，例如 `dashboard-chart.png`

## 如何在教程中引用

放在本目录下的图片，引用时用根绝对路径：

```md
![核心图表效果](/images/00-overview/dashboard-chart.png)
```

注意：**不要**写成相对路径（如 `../images/...`），根绝对路径在 cleanUrls 和移动文件时都不会出错。

## 说明

- 本目录属于 `docs/public/`，构建时会原样复制到站点根路径。
- 截图建议用 PNG；图片尽量压缩后再放入，避免网页变慢。
