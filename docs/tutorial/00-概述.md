# 概述：用 Excel 做出 BI 数据面板网页

## 这是什么

这个教程教你用 `WorkBuddy + Excel` 做出一套 **BI 数据面板网页**——把一张普通 Excel 表格，变成能在浏览器里打开、能筛选、能看到图表的看板。

## 能做什么

- 把 Excel 数据变成可视化的网页看板
- 关键指标一眼看清（指标卡片）
- 按业务字段筛选数据（部门、时间、地区……）
- 生成后打包发给同事，双击就能打开，不用装任何东西

## 适合谁

- 不会写代码，但希望能做出可展示数据看板的人
- 想先跑通业务原型、后续再逐步工程化的人
- 希望借助 WorkBuddy 等 AI 工具，按规则快速生成看板的人

## 读完教程你能做到

1. 准备一份结构清晰的 Excel 数据表
2. 写一段提示词，让 AI 帮你生成看板页面
3. 双击打开看板，验证效果
4. 打包成离线文件，发给同事直接使用

## 这套模板特别在哪

模板内置了**规则**和**技能**，让 AI 每次生成的代码风格统一、能复用现成能力。这部分由技术人员维护，你不用管，只管用结果。

另外，模板做出来的看板是**免构建**的——做完双击 `index.html` 就能打开，完全离线，发给谁都能看。
