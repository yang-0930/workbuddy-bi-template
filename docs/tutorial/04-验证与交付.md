# 验证与交付：预览效果、打包发送

## 这一步要做什么

看板生成后，先自己验证一遍，确认没问题再打包发给同事。

## 1. 预览看板

直接双击 `src/index.html`，在浏览器里打开看板。

逐项检查：

- **指标数值**是否正确（和 Excel 对得上）
- **图表**是否正常显示
- **筛选**是否生效（切换条件后数据跟着变）
- **移动端**是否能看（如果需要的话）

::: tip 打不开或空白？
打开浏览器控制台（按 F12），看有没有红色报错。最常见的是依赖文件缺失或路径不对——检查 `src/vendor/` 里的库是否齐全。
:::

## 2. 打包发给同事

确认无误后，用打包脚本把 `src/` 压缩成离线 zip：

**macOS / Linux / Git Bash：**

```bash
./scripts/build.sh
```

**Windows 原生 CMD / PowerShell：**

```cmd
scripts\build.bat
```

打包完成后，`dist/` 目录下会生成 `line-insight.zip`。

## 3. 发给同事

把 `line-insight.zip` 发出去即可。对方解压后双击 `index.html` 就能打开看板，**不用装任何东西**——这就是免构建模板的好处。
